Lektion 1.3 — Teil 1: React Einführung

Komponenten & Props (einfach)

React ca. 60 min Zwischenschritt

Lernziele

  • Komponenten als wiederverwendbare UI-Bausteine verstehen
  • Einfache Props zwischen Eltern- und Kindkomponenten weitergeben
  • Ohne komplizierte Typ-Tricks eine kleine Struktur aufbauen
  • Erste Aufteilung von App.tsx in mehrere Dateien umsetzen

1 — Idee: Eine große App in kleine Teile zerlegen

In Lektion 1.2 war alles in einer Datei. Das war für den Start gut, wird aber schnell unübersichtlich. Deshalb teilen wir die Oberfläche jetzt in kleine Komponenten auf.

Eine Komponente ist einfach eine Funktion, die JSX zurückgibt. Eine andere Komponente kann sie dann wie ein eigenes HTML-Element verwenden.

Sehr einfache Komponente TypeScript 
const HelloBox = () => {
  return <div>Hallo vom FlugBoard</div>;
};

function App() {
  return (
    <main>
      <HelloBox />
    </main>
  );
}

2 — Props ohne Ballast

Props sind Eingabewerte für Komponenten.

Mini-Beispiel: ein String-Prop TypeScript 
const Welcome = (props: { name: string }) => {
  return <p>Hallo {props.name}!</p>;
};

function App() {
  return <Welcome name="Max" />;
}
src/components/FlightRow.tsx TypeScript 
type FlightRowProps = {
  flightNumber: string;
  airline: string;
  destination: string;
  time: string;
};

const FlightRow = (props: FlightRowProps) => {
  return (
    <tr>
      <td>{props.flightNumber}</td>
      <td>{props.airline}</td>
      <td>{props.destination}</td>
      <td>{props.time}</td>
    </tr>
  );
};

export default FlightRow;

Bewusst einfacher Schritt

Diese Lektion ist als sanfter Einstieg gedacht. Die erweiterten TypeScript-Muster (Union-Typen, Record, Destructuring, Spread) kommen erst in der Lektion 1.4.

Projektschritt 1.3

Erste Komponenten auslagern

Wir zerlegen die statische Tabelle aus L01 in zwei einfache Komponenten: AirportHeader und FlightRow. Styling bleibt wie im Projekt standardmäßig in CSS-Dateien pro Komponente.

src/App.tsx TypeScript 
import './App.css';
import AirportHeader from './components/AirportHeader';
import FlightRow from './components/FlightRow';

function App() {
  return (
    <div className="app-page">
      <AirportHeader airportName="Flughafen Wien-Schwechat" />

      <table className="flight-table">
        <thead>
          <tr>
            <th>Flug</th>
            <th>Airline</th>
            <th>Ziel</th>
            <th>Zeit</th>
          </tr>
        </thead>
        <tbody>
          <FlightRow
            flightNumber="OS123"
            airline="Austrian Airlines"
            destination="London Heathrow (LHR)"
            time="10:30"
          />
          <FlightRow
            flightNumber="LH456"
            airline="Lufthansa"
            destination="Frankfurt (FRA)"
            time="11:15"
          />
        </tbody>
      </table>
    </div>
  );
}

export default App;
src/components/AirportHeader.tsx TypeScript 
import './AirportHeader.css';

const AirportHeader = ({ airportName }: { airportName: string }) => {
  return (
    <header className="airport-header">
      <h1 className="airport-header__title">✈ FlugBoard</h1>
      <p className="airport-header__subtitle">{airportName}</p>
    </header>
  );
};

export default AirportHeader;

Häufige Fehler

Fehler: Komponentenname klein geschrieben

<flightrow /> wird als HTML-Tag interpretiert, nicht als React-Komponente.

Komponenten immer in PascalCase schreiben: <FlightRow />.

Fehler: Props-Name passt nicht

Du übergibst destination, die Komponente liest aber props.airport.

Prop-Namen beim Aufruf und in der Komponente identisch halten.

Fehler: Datei nicht exportiert

Ohne export default kann die Komponente nicht importiert werden.

Jede Komponenten-Datei mit export default ...; abschließen.

Aufgaben

Aufgabe 1 Dritte Zeile als Komponente

Füge eine dritte FlightRow-Instanz für BA234 hinzu.

Aufgabe 2 Header-Text erweitern

Gib der Header-Komponente ein zweites Prop subtitle und zeige es unter dem Flughafennamen an.

Aufgabe 3 Spalte Status ergänzen

Erweitere FlightRow um ein Prop status: string und zeige den Wert als fünfte Spalte an.

Bonus Click-Handler auf Zeile

Füge ein Prop onRowClick hinzu und gib bei Klick auf eine Zeile die Flugnummer in der Konsole aus.
