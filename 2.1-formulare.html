Controlled vs. Uncontrolled Components

In React gibt es zwei Paradigmen für Formulareingaben: Controlled Components werden durch React-State gesteuert – React ist der einzige Wahrheitsspeicher (Single Source of Truth). Uncontrolled Components verwalten ihren eigenen Wert im DOM; React greift nur bei Bedarf per Ref darauf zu.

Controlled vs. Uncontrolled TypeScript 
import { useState, useRef } from 'react';

// --- CONTROLLED (empfohlen für die meisten Fälle) ---
// React steuert den Wert über State. Jede Änderung läuft über den State-Setter.
const ControlledBeispiel = () => {
  const [suchtext, setSuchtext] = useState('');

  return (
    <input
      type="text"
      value={suchtext}           // Wert aus State
      onChange={e => setSuchtext(e.target.value)}  // State bei Änderung aktualisieren
      placeholder="Flugnummer suchen..."
    />
  );
};

// --- UNCONTROLLED (für spezielle Fälle, z.B. Datei-Uploads) ---
// Das DOM verwaltet den Wert. React liest ihn nur bei Bedarf via Ref.
const UncontrolledBeispiel = () => {
  const inputRef = useRef<HTMLInputElement>(null);

  const handleSubmit = () => {
    // Wert aus dem DOM lesen
    const wert = inputRef.current?.value;
    console.log('Eingegebener Wert:', wert);
  };

  return (
    <>
      <input ref={inputRef} type="text" defaultValue="Startwert" />
      <button onClick={handleSubmit}>Lesen</button>
    </>
  );
};
✓
Wann Controlled, wann Uncontrolled?

Für fast alle Formulare: Controlled. Du hast jederzeit Zugriff auf den aktuellen Wert, kannst ihn validieren, transformieren (z.B. Großbuchstaben erzwingen) und programmatisch setzen. Uncontrolled ist hauptsächlich für <input type="file"> nötig, da Datei-Inputs aus Sicherheitsgründen nicht per JavaScript gesteuert werden können.

TypeScript Event-Typen

Jedes HTML-Eingabeelement hat seinen eigenen Event-Typ in React. Das generische HTMLElement funktioniert nicht, weil z.B. e.target.value nur bei HTMLInputElement und HTMLSelectElement existiert. Die korrekten Typen zu kennen vermeidet TypeScript-Fehler.

Event-Typen in TypeScript TypeScript 
import { FlightType, FlightStatus } from '../types/flight';

// Text-Input: React.ChangeEvent<HTMLInputElement>
const handleTextChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  const wert: string = e.target.value;
  setSuchtext(wert);
};

// Select-Element: React.ChangeEvent<HTMLSelectElement>
// ACHTUNG: e.target.value ist immer string → Type Assertion nötig!
const handleTypeChange = (e: React.ChangeEvent<HTMLSelectElement>) => {
  const typ = e.target.value as FlightType;  // Type Assertion
  setFlightType(typ);
};

// Checkbox: e.target.checked (kein .value!)
const handleCheckboxChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  const checked: boolean = e.target.checked;
  setNurPuenktlich(checked);
};

// Formular-Submit: React.FormEvent<HTMLFormElement>
const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
  e.preventDefault();  // Verhindert den Standard-Seiten-Reload!
  // Formulardaten verarbeiten...
};

// Textarea: ebenfalls React.ChangeEvent<HTMLTextAreaElement>
const handleTextareaChange = (e: React.ChangeEvent<HTMLTextAreaElement>) => {
  setNotiz(e.target.value);
};

Suchfeld für das FlugBoard

Eine Suchleiste ist eines der häufigsten UI-Patterns. Wir erstellen eine wiederverwendbare SearchBar-Komponente als Controlled Component. Die eigentliche Filter-Logik liegt in App.tsx (Lifting State Up).

src/components/SearchBar.tsx TypeScript 
interface SearchBarProps {
  value: string;
  onChange: (value: string) => void;
  placeholder?: string;
}

/**
 * Wiederverwendbares Suchfeld.
 * Der Elternteil kontrolliert den Wert über den onChange-Callback.
 */
const SearchBar = ({
  value,
  onChange,
  placeholder = 'Flugnummer oder Ziel suchen...',
}: SearchBarProps) => {
  return (
    <div className="search-bar">
      {/* Such-Icon als dekoratives Element */}
      <span className="search-icon">
        🔍
      </span>
      <input
        type="text"
        value={value}
        onChange={(e) => onChange(e.target.value)}
        placeholder={placeholder}
        className="search-input"
      />
      {/* Löschen-Button nur anzeigen wenn Eingabe vorhanden */}
      {value && (
        <button
          onClick={() => onChange('')}
          className="search-clear-btn"
        >
          ×
        </button>
      )}
    </div>
  );
};

export default SearchBar;

Filter-Bar mit Select-Elementen

Select-Elemente (<select>) funktionieren in React genau wie Inputs: wir binden value an State und aktualisieren ihn per onChange. Da e.target.value immer den Typ string hat, ist eine Type Assertion notwendig.

src/components/FilterBar.tsx TypeScript 
import { FlightType, FlightStatus } from '../types/flight';

type FilterType   = 'all' | FlightType;
type StatusFilter = 'all' | FlightStatus;

interface FilterBarProps {
  typeFilter:     FilterType;
  statusFilter:   StatusFilter;
  onTypeChange:   (value: FilterType) => void;
  onStatusChange: (value: StatusFilter) => void;
}

/**
 * Filterleiste mit Typ- und Status-Filter.
 */
const FilterBar = ({
  typeFilter,
  statusFilter,
  onTypeChange,
  onStatusChange,
}: FilterBarProps) => {
  return (
    <div className="filter-bar">
      <span className="filter-label">
        Filter:
      </span>

      {/* Typ-Filter */}
      <select
        value={typeFilter}
        onChange={(e) => onTypeChange(e.target.value as FilterType)}
        className="filter-select"
      >
        <option value="all">Alle Flüge</option>
        <option value="departure">Nur Abflüge</option>
        <option value="arrival">Nur Ankünfte</option>
      </select>

      {/* Status-Filter */}
      <select
        value={statusFilter}
        onChange={(e) => onStatusChange(e.target.value as StatusFilter)}
        className="filter-select"
      >
        <option value="all">Alle Flüge</option>
        <option value="on-time">Pünktlich</option>
        <option value="delayed">Verspätet</option>
        <option value="boarding">Boarding</option>
        <option value="departed">Abgeflogen</option>
        <option value="landed">Gelandet</option>
        <option value="cancelled">Annulliert</option>
      </select>

      {/* Aktive Filter anzeigen / zurücksetzen */}
      {(typeFilter !== 'all' || statusFilter !== 'all') && (
        <button
          onClick={() => { onTypeChange('all'); onStatusChange('all'); }}
          style={{ ...selectStyle, background: 'transparent', color: '#f85149', border: '1px solid #f8514944' }}
        >
          × Zurücksetzen
        </button>
      )}
    </div>
  );
};

export default FilterBar;

Formular: Neuen Flug hinzufügen

Das Herzstück dieser Lektion: ein vollständiges Formular mit Validierung. Wir verwenden separate useState-Aufrufe für jedes Feld – das ist bei vielen Feldern etwas ausführlich, aber sehr explizit und gut lesbar. Eine Alternative wäre ein einzelner State mit einem Objekt (beide Ansätze sind gültig).

src/components/AddFlightForm.tsx TypeScript 
import { useState } from 'react';
import { Flight, FlightType } from '../types/flight';

interface AddFlightFormProps {
  onAdd:    (flight: Flight) => void;
  onCancel: () => void;
}

/**
 * Formular zum Hinzufügen eines neuen Fluges.
 * Pflichtfelder: Flugnummer, Airline, Zeit, Flughafen.
 */
const AddFlightForm = ({ onAdd, onCancel }: AddFlightFormProps) => {
  // Ein State pro Formularfeld
  const [flightNumber,   setFlightNumber]   = useState('');
  const [airline,        setAirline]        = useState('');
  const [type,           setType]           = useState<FlightType>('departure');
  const [scheduledTime,  setScheduledTime]  = useState('');
  const [airport,        setAirport]        = useState('');
  const [terminal,       setTerminal]       = useState('T1');
  const [gate,           setGate]           = useState('');
  const [errors,         setErrors]         = useState<Record<string, string>>({});

  const FLIGHT_NUMBER_PATTERN = /^[A-Z]{2}\d{3,4}$/;

  // Validierungsfunktion – gibt Fehler-Objekt zurück
  const validate = (): Record<string, string> => {
    const errs: Record<string, string> = {};
    const normalizedFlightNumber = flightNumber.trim().toUpperCase();
    if (!normalizedFlightNumber) {
      errs.flightNumber = 'Flugnummer ist erforderlich';
    } else if (!FLIGHT_NUMBER_PATTERN.test(normalizedFlightNumber)) {
      errs.flightNumber = 'Flugnummer muss genau 2 Buchstaben und 3 oder 4 Ziffern enthalten (z.B. OS123).';
    }
    if (!airline.trim())       errs.airline       = 'Airline ist erforderlich';
    if (!scheduledTime)        errs.scheduledTime = 'Abflugzeit ist erforderlich';
    if (!airport.trim())       errs.airport       = 'Flughafen ist erforderlich';
    // Zeitformat prüfen: HH:MM
    if (scheduledTime && !/^\d{2}:\d{2}$/.test(scheduledTime)) {
      errs.scheduledTime = 'Format: HH:MM (z.B. 14:30)';
    }
    return errs;
  };

  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();  // Kein Seiten-Reload!

    const validationErrors = validate();
    if (Object.keys(validationErrors).length > 0) {
      setErrors(validationErrors);
      return;
    }

    // Neues Flight-Objekt erstellen
    const newFlight: Flight = {
      id:            Date.now(),          // Einfache temporäre ID
      flightNumber:  flightNumber.trim().toUpperCase(),
      airline:       airline.trim(),
      type,
      scheduledTime,
      status:        'on-time',           // Neuer Flug startet als pünktlich
      airport:       airport.trim(),
      terminal:      terminal || 'T1',
      gate:          gate.trim() || undefined,
    };

    onAdd(newFlight);
  };

  // Wiederverwendbarer Style für alle Inputs
  const inputStyle: React.CSSProperties = {
    width: '100%',
    padding: '0.5rem 0.75rem',
    background: '#1c2128',
    border: '1px solid #30363d',
    borderRadius: '6px',
    color: '#e6edf3',
    fontSize: '0.875rem',
    boxSizing: 'border-box',
  };

  const errorStyle: React.CSSProperties = {
    color: '#f85149',
    fontSize: '0.75rem',
    marginTop: '0.2rem',
  };

  const labelStyle: React.CSSProperties = {
    display: 'block',
    marginBottom: '0.25rem',
    fontSize: '0.8rem',
    color: '#8b949e',
  };

  return (
    <form
      onSubmit={handleSubmit}
      style={{
        background: '#161b22',
        border: '1px solid #30363d',
        borderRadius: '8px',
        padding: '1.5rem',
        marginBottom: '1.5rem',
      }}
    >
      <h3 style={{ color: '#3fb950', marginBottom: '1.25rem', fontSize: '1rem' }}>
        Neuen Flug hinzufügen
      </h3>

      <div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: '0 1rem' }}>
        {/* Flugnummer */}
        <div style={{ marginBottom: '0.75rem' }}>
          <label style={labelStyle}>Flugnummer *</label>
          <input
            style={{ ...inputStyle, borderColor: errors.flightNumber ? '#f85149' : '#30363d' }}
            value={flightNumber}
            onChange={e => setFlightNumber(e.target.value)}
            placeholder="OS123"
          />
          {errors.flightNumber && <p style={errorStyle}>{errors.flightNumber}</p>}
        </div>

        {/* Airline */}
        <div style={{ marginBottom: '0.75rem' }}>
          <label style={labelStyle}>Airline *</label>
          <input
            style={{ ...inputStyle, borderColor: errors.airline ? '#f85149' : '#30363d' }}
            value={airline}
            onChange={e => setAirline(e.target.value)}
            placeholder="Austrian Airlines"
          />
          {errors.airline && <p style={errorStyle}>{errors.airline}</p>}
        </div>

        {/* Typ */}
        <div style={{ marginBottom: '0.75rem' }}>
          <label style={labelStyle}>Typ *</label>
          <select
            style={inputStyle}
            value={type}
            onChange={e => setType(e.target.value as FlightType)}
          >
            <option value="departure">Abflug</option>
            <option value="arrival">Ankunft</option>
          </select>
        </div>

        {/* Zeit */}
        <div style={{ marginBottom: '0.75rem' }}>
          <label style={labelStyle}>{type === 'departure' ? 'Abflugzeit' : 'Ankunftszeit'} *</label>
          <input
            style={{ ...inputStyle, borderColor: errors.scheduledTime ? '#f85149' : '#30363d' }}
            type="time"
            value={scheduledTime}
            onChange={e => setScheduledTime(e.target.value)}
          />
          {errors.scheduledTime && <p style={errorStyle}>{errors.scheduledTime}</p>}
        </div>

        {/* Flughafen */}
        <div style={{ marginBottom: '0.75rem' }}>
          <label style={labelStyle}>{type === 'departure' ? 'Zielflughafen' : 'Herkunftsflughafen'} *</label>
          <input
            style={{ ...inputStyle, borderColor: errors.airport ? '#f85149' : '#30363d' }}
            value={airport}
            onChange={e => setAirport(e.target.value)}
            placeholder="London Heathrow (LHR)"
          />
          {errors.airport && <p style={errorStyle}>{errors.airport}</p>}
        </div>

        {/* Terminal */}
        <div style={{ marginBottom: '0.75rem' }}>
          <label style={labelStyle}>Terminal</label>
          <select style={inputStyle} value={terminal} onChange={e => setTerminal(e.target.value)}>
            <option>T1</option>
            <option>T2</option>
            <option>T3</option>
          </select>
        </div>

        {/* Gate (optional) */}
        <div style={{ marginBottom: '0.75rem' }}>
          <label style={labelStyle}>Gate (optional)</label>
          <input
            style={inputStyle}
            value={gate}
            onChange={e => setGate(e.target.value)}
            placeholder="B12"
          />
        </div>
      </div>

      {/* Schaltflächen */}
      <div style={{ display: 'flex', gap: '0.75rem', marginTop: '0.5rem' }}>
        <button
          type="submit"
          style={{
            padding: '0.5rem 1.25rem',
            background: '#3fb950',
            border: 'none',
            borderRadius: '6px',
            color: '#000',
            fontWeight: 600,
            cursor: 'pointer',
            fontSize: '0.875rem',
          }}
        >
          Hinzufügen
        </button>
        <button
          type="button"
          onClick={onCancel}
          style={{
            padding: '0.5rem 1.25rem',
            background: 'transparent',
            border: '1px solid #30363d',
            borderRadius: '6px',
            color: '#8b949e',
            cursor: 'pointer',
            fontSize: '0.875rem',
          }}
        >
          Abbrechen
        </button>
      </div>
    </form>
  );
};

export default AddFlightForm;

Suche, Filter & Neuen Flug hinzufügen

Das FlugBoard wird vollständig interaktiv: Suche, Filterung und das Hinzufügen neuer Flüge sind möglich. App.tsx wird zum zentralen State-Manager.

App.tsx – Vollständiger State TypeScript 
import { useState } from 'react';
import { Flight, FlightType, FlightStatus } from './types/flight';
import { sampleFlights } from './data/flights';
import SearchBar from './components/SearchBar';
import FilterBar from './components/FilterBar';
import FlightBoard from './components/FlightBoard';
import AddFlightForm from './components/AddFlightForm';

type TypeFilter   = 'all' | FlightType;
type StatusFilter = 'all' | FlightStatus;

function App() {
  const [flights, setFlights]           = useState<Flight[]>(sampleFlights);
  const [searchQuery, setSearchQuery]   = useState('');
  const [typeFilter, setTypeFilter]     = useState<TypeFilter>('all');
  const [statusFilter, setStatusFilter] = useState<StatusFilter>('all');
  const [showAddForm, setShowAddForm]   = useState(false);

  // Flüge hinzufügen
  const handleAddFlight = (flight: Flight) => {
    setFlights(prev => [...prev, flight]);
    setShowAddForm(false);  // Formular nach Einreichen schließen
  };

  // Alle aktiven Filter anwenden
  const filteredFlights = flights
    .filter(f => typeFilter === 'all' || f.type === typeFilter)
    .filter(f => statusFilter === 'all' || f.status === statusFilter)
    .filter(f => {
      if (!searchQuery) return true;
      const q = searchQuery.toLowerCase();
      return (
        f.flightNumber.toLowerCase().includes(q) ||
        f.airport.toLowerCase().includes(q) ||
        f.airline.toLowerCase().includes(q)
      );
    });

  return (
    <div className="app-page">
      <header className="app-header">
        <h1 className="app-title">✈ FlugBoard</h1>
        <button onClick={() => setShowAddForm(v => !v)} style={{ /* ... */ }}>
          {showAddForm ? 'Abbrechen' : '+ Flug hinzufügen'}
        </button>
      </header>

      {showAddForm && (
        <AddFlightForm onAdd={handleAddFlight} onCancel={() => setShowAddForm(false)} />
      )}

      <SearchBar value={searchQuery} onChange={setSearchQuery} />
      <FilterBar
        typeFilter={typeFilter}
        statusFilter={statusFilter}
        onTypeChange={setTypeFilter}
        onStatusChange={setStatusFilter}
      />

      <FlightBoard
        flights={filteredFlights.filter(f => f.type === 'departure')}
        title={`Abflüge (${filteredFlights.filter(f => f.type === 'departure').length})`}
      />
      <FlightBoard
        flights={filteredFlights.filter(f => f.type === 'arrival')}
        title={`Ankünfte (${filteredFlights.filter(f => f.type === 'arrival').length})`}
      />
    </div>
  );
}

export default App;

Häufige Fehler

Fehler: e.preventDefault() in onSubmit vergessen

Ohne e.preventDefault() führt das Absenden des Formulars einen Standard-HTTP-Request durch und die Seite wird neu geladen. In React-SPAs ist das unerwünscht – der State geht verloren und die App startet neu.

const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => { e.preventDefault(); ... }

Fehler: Select-Wert ohne Type Assertion

e.target.value hat in TypeScript immer den Typ string, auch wenn wir wissen, dass nur gültige FlightType-Werte kommen. Ohne Type Assertion bekommt man einen TypeScript-Fehler beim Zuweisen an die State-Variable.

Type Assertion verwenden: e.target.value as FlightType

Fehler: Checkbox value statt checked

Bei Checkboxen ist das relevante Prop checked (ein Boolean), nicht value (ein String). e.target.checked statt e.target.value verwenden.

<input type="checkbox" checked={bool} onChange={e => setState(e.target.checked)} />

Fehler: Formular ohne type="button" bei Buttons innerhalb eines Forms

Alle <button>-Elemente innerhalb eines <form> haben standardmäßig type="submit". Ein „Abbrechen“-Button löst damit unerwartet das Formular-Submit aus.

Buttons ohne Submit-Funktion explizit mit type="button" auszeichnen.

Aufgaben

Aufgabe 1 Suchfeld einbauen

Füge ein Suchfeld in App.tsx hinzu. Es soll Flüge nach Flugnummer, Flughafen und Airline filtern.

  • Erstelle die SearchBar-Komponente mit value und onChange-Props
  • Suche case-insensitive mit .toLowerCase().includes()
  • Füge ein „×“-Symbol hinzu, das das Suchfeld leert
  • Zeige die Anzahl der Treffer unter dem Suchfeld an: „5 Flüge gefunden“
Aufgabe 2 FilterBar erstellen

Erstelle die FilterBar-Komponente mit Typ-Filter und Status-Filter.

  • Zwei Select-Elemente: eines für Typ (Alle/Abflüge/Ankünfte), eines für Status
  • Type Assertion bei onChange verwenden
  • Einen „Zurücksetzen“-Button einbauen, der nur erscheint wenn ein Filter aktiv ist
  • Die Filterlogik liegt in App.tsx, nicht in der FilterBar
Aufgabe 3 AddFlightForm implementieren

Erstelle das vollständige Formular zum Hinzufügen eines neuen Fluges mit Validierung.

  • Pflichtfelder: Flugnummer, Airline, Zeit, Flughafen (alle prüfen)
  • Fehler-Messages direkt unter dem jeweiligen Feld anzeigen (rotes Styling)
  • Nach erfolgreichem Submit: Formular schließen und Flug zur Liste hinzufügen
  • Zeitfeld als <input type="time"> implementieren
Bonus Flug löschen mit Bestätigung

Füge einen Löschen-Button in FlightCard hinzu.

  • Ein kleines Papierkorb-Symbol (🗑) rechts in jeder Zeile
  • Beim Klick: window.confirm('Flug wirklich löschen?') – nur wenn der Nutzer bestätigt, wird der Flug entfernt
  • Der Flug wird per Callback aus dem State in App.tsx gelöscht: setFlights(prev => prev.filter(f => f.id !== id))
  • Nach dem Löschen des ausgewählten Fluges: selectedFlight auf null setzen
