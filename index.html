Projektidee: FlugBoard

Im Mittelpunkt des Kurses steht das Projekt FlugBoard — eine Echtzeit-Fluganzeigetafel ähnlich einem Abflug-/Ankunftsmonitor an einem realen Flughafen. Die App wird in jeder Lektion um neue Konzepte und Features erweitert, sodass am Ende eine vollständige Web-App (mit React und Next.js) sowie eine native Mobile-App (mit React Native) entstehen.

Das Backend ist ein schlanker Deno + Hono-Server, der Flugdaten als JSON bereitstellt. Ab Lektion 06 wird die App an dieses Backend angebunden.
